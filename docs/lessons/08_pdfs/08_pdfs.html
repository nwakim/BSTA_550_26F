Discrete vs. Continuous RVs

  • For a discrete RV, the set of possible values is either finite or can be put into a countably infinite list.

  • Continuous RVs take on values from continuous intervals, or unions of continuous intervals

How to define probabilities for continuous RVs?

Discrete RV \(X\):

  • pmf: \(p_X(x) = P(X=x)\)

Continuous RV \(X\):

  • density: \(f_X(x)\)
  • probability: \(P(a \leq X \leq b) = \int_a^b f_X(x)dx\)

What is a probability density function?

Probability density function

The probability distribution, or probability density function (pdf), of a continuous random variable \(X\) is a function \(f_X(x)\), such that for all real values \(a,b\) with \(a \leq b\),

\[\mathbb{P}(a \leq X \leq b) = \int_a^b f_X(x)dx\]

Remarks:

  1. Note that \(f_X(x) \neq \mathbb{P}(X=x)\)!!!

  2. In order for \(f_X(x)\) to be a pdf, it needs to satisfy the properties

    • \(f_X(x) \geq 0\) for all \(x\)

    • \(\int_{-\infty}^{\infty} f_X(x)dx=1\): the total area under the curve is 1

Use R to simulate known distributions (1/2)

  • We can use R to simulate continuous random variables and visualize their distributions
  • For example, we can simulate a uniform distribution between 2.5 and 3: \(f_X(x) = 2\) for \(2.5 \leq x \leq 3\)
set.seed(8)
reps <- 10000
uniform_sims <- tibble(
  x = runif(n = reps, min = 2.5,
            max = 3)
  )
head(uniform_sims)
1
Set the random seed once, so everyone gets the same random numbers.
2
Save the number of simulated values as reps, so it is easy to change later.
3
tibble() makes a table, which we save as uniform_sims.
4
runif() draws random values from a uniform distribution. n is how many values, and min and max are the ends of the interval.
5
head() shows the first 6 rows. Every value is a decimal number between 2.5 and 3. Note the slides show a rounded value. 
# A tibble: 6 × 1
      x
  <dbl>
1  2.73
2  2.60
3  2.90

Plot the simulated values and the pdf 
ggplot(uniform_sims, aes(x = x, y = after_stat(density))) +
  geom_histogram(binwidth = 0.025, boundary = 2.5,
                 color = "black", fill = "lightblue") +
  geom_hline(yintercept = 2, color = "red", linewidth = 1.5) +
  labs(title = "Probability density function (pdf) of X",
       x = "x",
       y = "Density") +
  theme_minimal(base_size = 20)
1
after_stat(density) scales the bar heights so the total area of the bars is 1, like a pdf.
2
Each bar covers a width of 0.025. boundary = 2.5 starts the first bar exactly at 2.5.
3
The red line is the true pdf, \(f_X(x) = 2\).
4
Add a title and axis labels.
5
Use a clean theme with larger text.

Use R to simulate known distributions (2/2)

  • We can use the simulated values to check our answers from Examples 1.2 to 1.5
uniform_sims |>
  summarise(
    prob_between = mean(x >= 2.7 & x <= 2.9),
    prob_equal   = mean(x == 2.9),
    prob_at_most = mean(x <= 2.8)
  )
1
Start with the 10,000 simulated values of x.
2
summarise() collapses the table into one row with a column for each probability.
3
x >= 2.7 & x <= 2.9 is TRUE when x is at least 2.7 and at most 2.9. The mean of TRUEs and FALSEs is the proportion of TRUEs, which approximates \(P(2.7 \leq X \leq 2.9)\).
4
The proportion of simulated values exactly equal to 2.9, which approximates \(P(X = 2.9)\).
5
The proportion of simulated values at most 2.8, which approximates \(P(X \leq 2.8)\). 
# A tibble: 1 × 3

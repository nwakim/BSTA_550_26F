Distributions of transformations of random variables

  • Often make transformations of RVs
    • Unit conversions (Celsius to Fahrenheit, minutes to hours)
    • Log-transforming a skewed biomarker
    • Turning a waiting time into a rate
  • A function of a random variable is a random variable
    • If \(X\) is a random variable and \(g\) is a function then \(Y=g(X)\) is a random variable
    • Since \(g(X)\) is a random variable it has a distribution
  • Two types:
    • Linear rescalings: \(g(u) = a + bu\)
    • Nonlinear transformations: e.g. \(g(u) = u^2\), \(g(u) = \log(u)\)
  • Our main tool today: simulate \(X\), transform every simulated value, then summarize

Our main tool: simulate, transform, summarize

The simulation method for transformations

To learn about the distribution of \(Y = g(X)\):

  1. Possible values: Find the possible values of \(Y\) (graph \(g\) over the possible values of \(X\))
  2. Simulate: Simulate many values of \(X\)
  3. Transform: Apply \(g\) to every simulated value: mutate(y = g(x))
  4. Summarize:
    • Probabilities: mean(y <= c) approximates \(P(Y \leq c)\)
    • Shape: a histogram of y
    • Center and spread: mean(y), sd(y)
  • This works for any function \(g\), as long as we can simulate \(X\)
  • We do not need the CDF of \(X\), the CDF of \(Y\), or a p*() function for \(Y\)

Simulating \(X\): three ways

How do we get simulated values of \(X\) in step 2?

  1. Named distribution: use its r*() function from Lessons 12 and 13 (runif(), rexp(), rgamma(), rnorm())

 

  1. Build it from simpler pieces: like the Gamma as a sum of exponentials (Lesson 13)

 

  1. Only have the pdf? Use grid sampling (next slide)
    • Lesson 9’s inverse CDF method needs the CDF
    • Grid sampling only needs the height of the pdf

Grid sampling: simulating from a pdf

  • Let \(U\) have pdf \(f_U(u)= \dfrac{4}{15}u^3\) for \(1\leq u \leq 2\). There is no r*() function for \(U\)!
  • Idea: a box model (Lesson 2). Fill a box with many evenly spaced values between 1 and 2, and make each ticket’s chance of being drawn proportional to the pdf’s height there
set.seed(1111)
reps <- 10000

u_grid <- seq(
  from = 1, 
  to = 2, 
  length.out = 1001
  )

u_sims <- tibble(sim = 1:reps) |>
  mutate(
    u = sample(u_grid, 
               size = n(), 
               replace = TRUE,
               prob = 4/15 * u_grid^3
               )
  )

Linear rescaling

Definition: Linear Rescaling

A linear rescaling is a transformation of the form \(g(u) = a + bu\), where \(a\) and \(b\) are constants

  • Thus, if we have a random variable, \(X\), then a linear rescaling of \(X\) could be \(M = g(X) = a + bX\)

  • For example, converting temperature from Celsius to Fahrenheit using \(g(u) = 32 + 1.8u\) is a linear rescaling.

Why the shape does not change

  • \(V = 1 - U\) flips \(U\) around: same shape, mirrored
  • In general, \(a + bX\) can shift (add \(a\)), stretch or squeeze (multiply by \(|b|\)), and flip (\(b < 0\))
    • Stretching the values out by \(|b|\) makes the histogram \(|b|\) times wider…
    • …so it must get \(|b|\) times shorter to keep the total area equal to 1
  • Center and spread change the way we saw in Lessons 10 and 11:
    • \(\mathbb{E}[a + bX] = a + b\,\mathbb{E}[X]\)
    • \(Var(a + bX) = b^2\, Var(X)\) and \(SD(a + bX) = |b|\, SD(X)\)

Linear rescaling of named distributions

For most named distributions, a linear rescaling stays in the same family, with new parameters:

If \(X \sim\) then is
\(\text{Normal}(\mu, \sigma^2)\) \(a + bX\) \(\text{Normal}(a + b\mu,\ b^2\sigma^2)\)
\(\text{Uniform}[l, r]\) \(a + bX\) (with \(b > 0\)) \(\text{Uniform}[a + bl,\ a + br]\)
\(\text{Exponential}(\lambda)\) \(cX\) (with \(c > 0\)) \(\text{Exponential}(\lambda / c)\)
\(\text{Gamma}(r, \lambda)\) \(cX\) (with \(c > 0\)) \(\text{Gamma}(r,\ \lambda / c)\)

  • Exponential and Gamma: only multiply, do not shift! \(X + 3\) can’t be close to 0, so it is not Exponential

  • Standardizing is a linear rescaling: if \(X \sim \text{Normal}(\mu, \sigma^2)\), then

\[Z = \dfrac{X - \mu}{\sigma} \sim \text{Normal}(0, 1)\]

Summary of linear rescaling

  • A linear rescaling of a random variable does not change the basic shape of its distribution, just the range of possible values.

    • It can flip it, widen it, condense it, and/or shift it

    • But it is not the same distribution: the possible values change

  • Normal, Uniform, Exponential, and Gamma RVs stay in the same family, with new parameters

  • Remember, do NOT confuse a random variable with its distribution

    • The random variable is the numerical quantity being measured
    • The distribution is the long run pattern of variation of many observed values of the random variable

Nonlinear transformations

  • What happens when we make a nonlinear transformation, like a logarithmic or square root transformation?

  • Nonlinear transformations do not necessarily preserve the distribution shape

  • Examples of nonlinear transformations:

    • \(g(u) = u^2\)
    • \(g(u) = \sqrt{u}\)
    • \(g(u) = \log(u)\)
    • \(g(u) = e^u\)
    • \(g(u) = \dfrac{1}{u}\)

  • There is usually no shortcut like the table for linear rescalings, so we use the simulation method

Rewriting events

  • Rewriting an event about \(Y = g(X)\) as an event about \(X\) helps us:
    • Find the possible values of \(Y\)
    • Check that our simulation summary is counting the right thing
    • Find an exact answer when we can find probabilities for \(X\) (a p*() function or a rectangle’s area)
  • Examples:
Event about \(Y\) Same event about \(X\)
\(\log(X) \leq 0.5\) \(X \leq e^{0.5}\)
\(X^2 \leq 0.25\) \(-0.5 \leq X \leq 0.5\) (two sides!)
\(\dfrac{1}{X} > 2\) (for \(X > 0\)) \(X < 0.5\) (the inequality flips!)
  • Graph \(g\) to see which values of \(X\) land in the event

Example: when there is no p*() function (1/2)

Example 6: Buses per hour

From Lesson 13: the time until 4 buses arrive is \(X \sim \text{Gamma}(r = 4, \lambda = 1/10)\), in minutes. The average number of buses per hour while we wait is

How accurate is a simulation? (1/2)

  • A simulation gives an approximation. Run it again with a new seed and the answer moves a little
  • How much it moves depends on the number of simulations
  • Let’s repeat the simulation from Example 3 200 times for each of 100, 1,000, and 10,000 simulations
accuracy_sims <- expand_grid(
    n_sims = c(100, 1000, 10000),
    run = 1:200
  ) |>
  uncount(n_sims, .remove = FALSE) |>
  mutate(
    u = sample(u_grid, size = n(), replace = TRUE, prob = u_grid^3)
  ) |>
  group_by(n_sims, run) |>
  summarise(estimate = mean(log(u) <= 0.5), .groups = "drop")
1
One row for every combination of simulation size and repeat: 3 sizes \(\times\) 200 runs.
2
uncount() copies each row n_sims times, so each run gets 100, 1,000, or 10,000 rows.
3
Grid sample one \(U\) for every row, like before.
4
Treat each run of each size separately.
5
Each run’s approximation of \(P(V \leq 0.5) = P(\log(U) \leq 0.5)\).

Summary of transformations

  • Linear rescalings keep the shape. Named distributions stay in the same family, with new parameters
  • Nonlinear transformations can change the shape of a distribution
    • Substituting into the pdf does not work
    • \(\mathbb{E}[g(X)]\) is not \(g(\mathbb{E}[X])\)
  • The simulation method works for any transformation: simulate \(X\), transform, summarize
  • Rewrite events about \(Y\) in terms of \(X\) to find possible values, check your simulation, and get exact answers when you can
